## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` copies `POST.json` (the address of the X post with the meme) to `/output/POST.json`. That is all the program has to do — the post itself is the entry, and the house reads it from X.
